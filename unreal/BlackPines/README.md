# Black Pines — Unreal Engine 5.8 native project

New Unreal C++ project. Godot is not the active engine for new development. This project has **not been compiled or opened in Unreal Editor** and Unreal 5.8 has **not been installed in this execution environment**. Requires a compatible Windows/Linux machine with Unreal Editor and Android SDK/NDK installed. Existing source is preserved for reference only; actual world import, AI, gameplay, mobile HUD, co-op, APK and device profiling are not yet complete.
